# Developer Notes

This repository is a personal reference library for software development,
system design, Git, and GitHub workflows.

## Contents

### [Git & GitHub Master Notes](git_github_master_notes.md)

A practical reference covering:

- Git fundamentals and repository states
- Branching, merging, rebasing, and recovery
- GitHub collaboration and pull requests
- Authentication, releases, GitHub CLI, and Actions
- Troubleshooting and common end-to-end workflows

### [Domains and DNS System Design Notes](domains_dns_system_design_notes.md)

System design and troubleshooting notes covering:

- Domain registration, DNS hosting, and application hosting
- Nameserver delegation and glue records
- DNS, HTTPS, TLS, and CAA records
- Redirects, propagation, CDNs, load balancing, and failover
- Email DNS records, monitoring, redundancy, and disaster recovery

## How to use this repository

Use the Git and GitHub notes as a command-oriented handbook, and the DNS
notes as a conceptual and troubleshooting reference. Examples use
placeholders or illustrative values; verify provider-specific details before
using commands or DNS records in production.
